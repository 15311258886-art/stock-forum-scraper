## 经验沉淀
1. `archive stats` 的「最近运行」列出的是全部记录而非仅一条，判断当日净增需交叉核对「每日汇总」表同名日期行求和。
1b. 本任务 Bash 命令若**路径不加引号**，含空格的 `F:/AI Agent部署知识库/...` 会被 shell 截断报 "No such file or directory"；统一 `cd "<abs>"` 后对相对路径/已加引号的绝对路径调用。
1c. trades 归零自诊断最小链路：session.get → `soup.select("p.topic-info")` 块数 → `nm.scan_names(body)` 词典命中 → `parser._extract_trades(body)`。DOM 有块 + 词典有命中 + 抽取为 0 = 内容无成交动作（正常）；DOM 块为 0 = 选择器漂移（需 inspect 校准）。
2. 原生 Windows curl 不认 `/tmp` 类 MSYS 路径；取接口返回体直接管道给 python 解析更稳。
3. openpyxl 读存档时用 `-c` 内联字符串拼接中文路径易出错，改写成临时 .py 脚本文件执行更可靠（用完即删）。
4. 「每日汇总」表列位：0 运行日期 / 1 站点 / 2 模式 / 3 新增交易 / 4 新增资讯 / 5 状态 / 6 备注。核对当日净增须按日期对第 3、4 列求和（同一天可能有多行）。

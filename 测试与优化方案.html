一、测试范围与方法

被测对象：本地看板（viewer/server.py 标准库 HTTP 服务 + viewer/static/app.js 单文件前端 + SQLite viewer/app.db），含国内股吧模块与海外舆情两模块（监控 + 国外驱动热点）。

三条测试线

  • 动态功能：枚举 do_GET/do_POST 全部路由，逐个探测状态码、返回结构、字段一致性；覆盖缺参/空参/超长参/Unicode/越界 id/不存在路径等边界；核对计数与明细的数值自洽。
  • 安全专项：静态代码审计 + 无害动态验证。覆盖路径穿越、CORS/CSRF/鉴权、TLS 校验、SQL 注入、前端 XSS、凭据与仓库卫生、网络暴露面、报错信息泄露。
  • UI 与数据一致性：真实 Chromium + 真实布局矩形断言（不靠肉眼）。10 个 tab、3 类抽屉 × 4 种关闭入口、拖拽与拉伸、四主题可读性、两档视口、空态与错误态；并对 /api/summary 与各列表接口逐项对账、检查示例数据混流。

只读约束与说明：三条线均未修改任何源码、未写入 app.db（测试前后 mtime 未变）、未调用任何写接口（/api/fetch、/api/demo、/api/sync_names、POST /api/overseas）。写接口的 CSRF/鉴权问题以代码级论证给出，未实际触发。

环境注意：本机 http_proxy 指向本机代理，Python urllib 默认会把 localhost 也交给代理——服务异常时会收到 502 而非 ConnectionRefused，易把"服务没起"误判成"服务报错"。所有探测均已显式绕过代理。

六、优化建议

主题建议
安全边界所有静态文件发送必须 resolve() 后判定归属；移除无条件 ACAO:*，改为仅回环来源放行；写接口统一校验 Origin/Host/Content-Type 并加一次性令牌；错误响应不泄露 Server 版本
数据可信度示例数据加 is_seed 列并在所有聚合中过滤；示例条目一律使用「示例源·」前缀，禁止复用真实源 key；缺失时间留空而非填当前时间，另设 fetched_at；趋势图对无时间条目显式标注条数
可观测性do_GET 外层统一 try/except，异常返回 500 JSON 并记日志；前端 api() 校验 r.ok 并提供可见错误条；消除静默降级（请求体解析失败应 400 而非当空对象继续）
口径一致性同一指标只保留一处计算入口（持有天数、共同持仓人数）；面板计数区分"抓取数"与"入库可用数"并分别标注；持久化 enabled 与 checked_at 并在界面呈现
前端健壮性esc() 补齐引号转义；所有字段读取带默认值；数值型断言非 NaN；拖拽/拉伸把手统一钳制在视口内；移除死代码分支与死接口
仓库卫生新增 .gitignore（app.db*、*.bak*、.browser-profile/、凭据导出、tools/shots*/）；凭据文件移出项目目录；跨平台权限处理不要只依赖 chmod

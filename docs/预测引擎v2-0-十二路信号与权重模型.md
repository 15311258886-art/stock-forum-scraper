## 二、权重模型：先验 × 覆盖置信度 × 实盘命中率

```
raw[k]  = prior[k] × hit_score × cov_blend
hit_score = 1 + eff × (hit_rate − 0.5) × 2        # T+5(0.6)+T+3(0.25)+T+10(0.15)，eff=样本量置信度
cov_blend = COVER_FLOOR + (1−COVER_FLOOR) × (1 − e^(−cov_n/COVER_K))   # 0.45 起
raw → 归一化 → 限幅 [W_MIN, W_MAX] → 再归一化
```

- `COVER_K = 30`、`COVER_FLOOR = 0.45`、`W_MIN/W_MAX = 0.02/0.34`
- `_history_coverage()` 只取 **engine_ver = 当前版本** 的 prediction_run.breadth_json（跨版本混用会污染）
- 冷启动（无复盘样本）时 `hit_score → 1.0`，权重自然退化为「先验 × 覆盖度」
- **调参入口**：只改 `predictor.py` 的 `SIGNALS` 里每路 `prior`，`_default_weights()` / `rescore()` 自动归一

### 为什么必须有覆盖度校正
旧口径里 extref 覆盖 2/157（1.3%）、sentiment 9/157（5.7%），却和 holders 157/157 拿一样的 `W_MIN` 底权；
tech 154/157（98%）反而被 `W_MAX` 按死。等于拿噪声当信号。覆盖度校正就是治这个。

### 2026-09-30 实跑结果
tech 18.87% > holders 14.68% > inst 9.95% > policy 9.30% > desk/ann 9.02% > board 6.95% > overseas 5.54% > sentiment 5.40% > follow 4.60% > lhb 3.80% > extref 2.86%，与先验顺序完全一致；第二轮 rescore 最大位移 0.000000（收敛）。

## 四、选手跟随的 bug（数据坐实）

旧代码读 `positions`，而它的 `post_time` 停在 **2021-06-20**（五年前快照）；
另一张 `trades` 有 2026-10-01 12:31 的实时成交。截图里 79 只「选手跟随」实际是五年前的数据。
现改走 `trades` + `person_scores.win_rate_20d/5d` 加权 + 时间衰减（当天 1.3 / 3 天内 1.1 / 10 天内 1.0 / 更早 0.6）。

## 五、六个坑（都是"看起来能跑、其实静默错"）

1. **rescore 漏乘 prior**：docstring 写三重乘、实现只写 `hit_score*cov_blend`。结果每次 rescore 都按覆盖度洗牌，龙虎榜（prior 最低）被抬到权重第三——与诉求相反。
2. **限幅顺序**：第一道限幅加在 raw 上 → 十二路全被夹到 W_MAX → 归一化回伪等权。**必须"归一化 → 夹 → 再归一化"**。
3. **旧维度残留行致命**：`predictor_score` 里六路的 `fund` 没删 → `load_weights` 口径校验永远失败 → rescore 权重永远读不回来。修法 `_drop_stale_signal_keys()` 挂进 `ensure_tables` 自愈（重启即收敛）；只删不补也不行，新路的行也要补 → 同时 `_ensure_score_rows(con, [])`。
4. **前端 PRED_SIG_META 没同步**：扩维度只改渲染逻辑，元数据表还停在旧六路 →「信号贡献」永远显示 6 路。修法：改 `let` + `syncPredSigMeta()` 从 API 覆盖键与名，图标留前端兜底（以后加维度只改 Python）。
5. **两套口径数**：`sig_stats._w`（先验归一）与 DB 权重不同源 → 前端两张表打架。generate 末尾把 rescore 的 `weights` 回写进 `prediction_run.breadth_json._w`。
6. **覆盖度跨版本混用**：v1.0 的 breadth 没有新维度键 → 新路覆盖算 0 被压到下限，旧路反被抬高（首日 rescore 出 tech 23%/follow 8.7% 反超 inst 6.6%）。

另：
- `sig_desk` 取消 asof 过滤 —— `stock_desk` 是快照语义，加 `date(scan_at)<=asof` 会把回补的历史日静默杀为 0。
- `sig_holders` 原按 free/total 双 scope 重复计数 + `hold_ratio` 又 ×100 → 算出「机构合计持股 30334%」。
- `sig_board`：`board_flow_samples` 没有 `id` 列（`ORDER BY id` 抛 OperationalError 被 except 吞成空信号）；跨 3 天相加会出「主力净流入 1189 亿」。

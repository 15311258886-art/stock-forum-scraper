## 怎么读这张表

1. **只看「到期数 ≥ 20」的行。** 其余行留着是为了看进度，不是看结论。
2. `t` 用**非重叠抽样**算的（同一天的票先压成一条，再按持有期切桶）。重叠窗口直接算 t 会把样本量虚报好几倍，这是本项目在 `cond_engine` 里已经踩过的坑。
3. `角色=排除` 的判据（创 20 日新高、量比 < 0.8）**超额为负才对** ——它是「别买」的判据，负超额说明避开它是对的。
4. 分来源看，别把六个持有期加起来看：同一批票在 1/3/5/20/60/120 上是 六条互相重叠的序列，加起来会把同一个事件数六遍。
5. 前向记账的价值随时间线性增长：T+1 次日就有分，T+120 要半年。**头一个月不要下任何结论。**

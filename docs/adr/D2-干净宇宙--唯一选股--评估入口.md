## D2 干净宇宙 = 唯一选股 / 评估入口
- **背景**：原选股从「博主文本挖名池」或 `positions∪lhb` 兜底出发，混入 ST / 退 / 博主噪声（「垃圾堆里挑垃圾」）。
- **结论**：所有选股 / 评估必须从 `evaluation_universe()`（= 有因子快照 ∩ 剔除池外）出发；剔除池**只含客观硬垃圾** = ST/退(212) + 无K线(28)（± 可选 illiquid），干净宇宙底池 5243 只。**博主噪声已从剔除池移除（见 D1），80 只释放回候选资格**（其因子需本机重跑 `viewer.indicators` 补齐）。
- **影响模块**：`api_funnel_score`、`strategy_sim.universe`、`kronos._pick_codes`、`universe_scan`、`strategy_templates`、`universe_filter`。
- **推翻条件**：剔除标准变化（如新增 illiquid）时更新 `universe_filter`，不改本结论。

## D47 · 2026-10-31 · 巡检尺子修三处：把「假红」和「真坏」分开

D46 收尾时按惯例跑点击巡检，41 面板报 16 项有问题。逐项核过：**14 项是真的空态**
（10-30 论坛停抓后有意留空）、**2 项是尺子过期**。尺子假红比真坏更危险——
它会让人习惯性忽略红色。三处一次修掉：

### ① 巴菲特选股：「面板:缺」——查的是一个已下线的 tab

巡检里配的是 `#learn/buffett` 的 `.bf-card`，但该 tab 早已并入「基金经理策略」，
整体是个自包含 iframe（`loadFundMasters()`，NAV fixed 项 key=`fundmasters`），
顶层面板根本不存在。改成在 iframe 内检测：分类数 / 标的总数 / 是否含「巴菲特」/
点一个标的后详情区是否真的展开。实测 **iframe 有 / 分类 6 / 标的 27 / 含巴菲特 / 点开详情 71 字**。

顺带记一条坑：**iframe 内容不计入宿主 `innerText`**，所以这类面板 `len` 恒为 0，
不能拿 `len < 40` 判空——现改为按框内标的总数判。

### ② `drill()` 的 document 兜底：会跨面板乱点

原实现在目标面板里找不到入口时 `findFirst(document)` 兜底，于是点到导航/刷新按钮，
报出「钻:BUTTON.btn → 开:none」这种既不是功能坏、也定位不到问题的假红。
改为：先在面板内展开所有 `<details:not([open])>` 再找一次，仍找不到就诚实报
`no-visible-entry`，**不跨面板乱点**。

### ③ 长期低位：选择器从来没匹配过

配的是 `.wt-sym[data-wt-open]`，而 lowbox 表里的代码链接实际是
`<a class="wt-code" data-wt-open=…>`（`lowboxTable()`）。从不匹配 → 一路退到
`[data-lb-add]`（「加入自选」按钮，点它本来就不开弹层）→ 每轮假红。
改为 `.wt-code[data-wt-open]` / `[data-wt-open]` / `[data-lb-more]` / `[data-lb-add]` 依次。

### ④ 博主共振：配了一个天然点不开的入口

该面板 30,050 字里 `[data-sym]` / `.stk` / `.chip` **全为 0** —— 它是一张纯展示页
（战法表 + 回测档案 + 图谱条目），本来就没有可点的个股节点。原配的 `.res-card`
是无点击事件的展示卡，点它必然 `open:none`。改为**不钻取**（entrySels 置空）。

### ⑤ 顺手补一条判据：行内展开 ≠ 没打开

`detectOpen()` 只认 `drawer` / `branchModal` / `fundModal` 三种弹层，
而有些面板点开是**详情直接铺在面板里**（行内展开），于是被判成 none。
补一条：钻取后若面板内容明显变长 → 记 `inline-expand`（弹层优先，这条只是兜底）。

### ⑥ 三个已物理删除的页面从巡检移除

`外部荐股验证` / `博主荐股` / `当红参赛股` —— app.js 记录「2026-10-29 进哥拍板
三页已物理删除」（opinion 类只剩研报评级）。保留检测只会每轮报「面板:缺」，
已注释掉（保留原行 + 下线说明，便于日后回溯）。

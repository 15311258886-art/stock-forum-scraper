## D8 数据链路判死必须顺调用链，grep 只能初筛（2026-10-30 全链路体检）
- **背景**：进哥要求「抓了没用的全停」。第一版凭「表名在 server.py / 前端零引用」停了 4 项，
  复核推翻 3 项：`auction_snapshot`（被 `auction.summary()` 读，是今日总览第一屏）、
  `extref_signals`（被 `ai_review` / `predictor` 直接 SQL 读）、`evo_knowledge`（被 `ai_review` 读）。
  只有 `intraday_snap` 是真的只进不出。
- **结论**：判死一条链路必须走完「表 → 函数 → API → 前端」四级；grep 表名只能用来初筛。
  停用一律走 `viewer/config.py` 的 `DISABLED_SCHED` / `INGEST_SOURCES` 开关（清单过滤），
  **不删代码、不删表**，改回一行即恢复。
- **影响模块**：`viewer/config.py`、`server._sched_tasks`、`server._sched_run_once`。
- **推翻条件**：若某链路确认永久废弃，可在季度清理时物理删除；此前一律走开关。

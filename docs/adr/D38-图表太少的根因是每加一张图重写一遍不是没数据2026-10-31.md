## D38 「图表太少」的根因是**每加一张图=重写一遍**，不是没数据（2026-10-31）

进哥原话：「应用当中利用图表或者是显示更清晰的元素呢，我感觉稍微少了一点。」
授权「如果有可以直接上，不用询问我的意见」。

### 根因诊断（先说为什么以前图少）

不是缺数据，也不是不想画 —— 是**画一张图的边际成本太高**。`app.js` 里散着 7~8 段手搓的
SVG 拼字符串（`ov-chart` / `ov2-pie` / `sc-hm-svg` / `lhbw-chart` / `lhbw-svg` …），
每段都自己算坐标、自己定色、自己处理边界。加第二张图的成本 ≈ 重写第一张，于是越用越少。

### 做了什么（三件，互不耦合）

1. **`viewer/static/viz.js` —— 零依赖 SVG 图表基元层**（`window.VIZ`）
   `diverging`（发散条形 + 95%CI 淡色带）/ `scatter`（带象限底色与标签避让）/
   `groupBars`（同期多持有期对照）/ `microBar`（表格内迷你条）+ `legend`。
   纯函数返回 SVG 字符串，**颜色只走 CSS 变量**，四个主题自动跟随。
   以后加图只传数据，不再碰坐标。

2. **「公告实证」面板**（`nav: research` 下，紧跟「信号回测」）
   把 `research/out/announcement_event_study.md`（115.8 万条公告 → 60 日冷却去重 →
   20 类 × 3 持有期 = 60 次检验）从一张表变成三张图 + 一个详表。核心结论：
   **利空标签有效（7 类 T+5 显著为负），利好标签无效（显著为正的一类都没有）**；
   `风险提示` 是陷阱（T+20 均值 +3.54% 但日胜率仅 41.2%，右尾驱动）。

3. **回归测试**（7 项 Python + 10 项 Node 渲染断言）
   `tests/test_ann_event_panel.py` + `tests/_ann_event_render.cjs`，
   后者补齐前者查不到的运行时空面板/undefined/SVG 未闭合。

### 为什么走静态数据文件、不新开 API 路由

`research/gen_ann_event_js.py` 把 md 解析成 `viewer/static/ann_event_data.js`（`window.ANN_EV`）。
理由：这是**离线研究产物**，只在重跑研究时变化，没有实时性；而静态文件按请求从磁盘读，
**改完刷新页面即生效、不需要重启查看器**。对比 `lhb_weather` 那次 —— 后端路由没注册，
前端只能写一句「接口尚未生效，需要重启」。数据文件由脚本生成、
`test_data_file_is_generated_not_hand_edited` 守着手改。

### 自查阶段抓到的 5 个真问题（都改在提交前）

| # | 问题 | 性质 |
|---|---|---|
| 1 | `P()` 自带 `%`，调用处又拼一个字面量 `%` → 渲染成 `-1.95%%` | **同一个 bug 犯了两次**，第一次靠看截图才发现 |
| 2 | 散点图四等分刻度 → 纵轴 1.8 / 0.7 / **-0.3**，零线被标成 -0.3 | **坐标轴错**，读图的人会判错方向；改用 nice ticks（1/2/2.5/5×10^k） |
| 3 | 分期图数值列右对齐到 `W-valW-gapR-2`，文本左缘压进绘图区 | 数字被条形盖住 |
| 4 | 「不显著」用降透明度表示，与「T+20 本来就浅」撞车 | 语义混淆；改为**空心虚线**，两套视觉语言不互占 |
| 5 | `<b>` 染成 `--bull` 红 → 「真的跌」是红的，而图里跌是绿的 | **同一面板内自相矛盾**；正文改明度差强调，方向色只留给图表 |

另修正一处**事实错误**：规则①原写「T+5 反而只到 -0.50%」，
实际 `股东减持` 是 T+1 −0.435% → T+5 −0.502% → T+20 −0.603%，**越拿越亏**，不是「只到」。
已改为「次日反应最确定（t 绝对值最大），之后幅度还在扩大」。

### 一个必须记住的加载顺序约束（踩过）

`app.js` 在**脚本顶层**就执行 `initNav()`，深链接（`#research/ann_event`）会在那一刻
立即 `selectNav → ANN.load()`。所以 `viz.js` / `ann_event_data.js` / `ann_event.js`
**必须排在 `app.js` 之前**，否则窗口里 `window.ANN` 仍是 undefined，
面板直接落到「脚本未加载」兜底提示 —— 而脚本本身是 200 正常返回的，极难从网络面板看出来。
`test_panel_registered_in_index_html` 已把这条顺序断言锁死。

## D36 「四支柱选股的远期超额」与「四路信号对 T+5 超额的 IC」不是同一个对象（2026-10-31）

起因：核对「权重是按哪个持有期拟合的」时，一度把 `pillars.py` 的 `per_pillar` 和 `evolve.py` 的
拟合口径当成同一件事，得出「四支柱的权重是按 T+5 拟合的」这个结论。**这个表述是错的**，
本节把两个对象钉死，防止以后再被混用。

### 1. 两个对象各自的定义（带代码锚点）

| | `pillars.state_json.per_pillar` | `evolve` 的 per-state 权重 |
|---|---|---|
| 衡量什么 | **四根支柱各自选出的股票**，在 T+1/3/5/10/20 各周期的**远期超额**与命中率 | **四路信号**（blogger / strategy / senti / engine）与个股未来收益的**秩相关（IC）** |
| 观测单位 | 支柱 × 周期 的**组合**统计（`hit_rate` = 跑赢池子的比例，`avg_alpha` = 平均超额） | 个股 × 信号日 的**横截面**样本，聚合成 IC |
| 代码锚点 | `pillars.py:1149-1162`，周期 `(1,3,5,10,20)`；`SELF_LEARN_PILLARS` 四根 | `evolve.py:62` `DIMS = ["blogger","strategy","senti","engine"]`；`evolve.py:312-317` |
| 持有期口径 | 逐周期分别统计，**没有单一"主周期"** | 固定单一：`bi = i0+1`（次日买）→ `fut = b[bi+5]`，`FIT_HORIZON = 5` |

关键区别：`per_pillar` 是**选股结果**的绩效（"这根支柱挑出来的票后来涨没涨"），
`evolve` 是**信号强度与未来收益的单调关系**（"这根信号给高分的时候，未来收益是不是也更高"）。
前者看绝对超额，后者看排序能力。**同一个 T+5 数字，在两边的含义不同。**

### 2. 为什么不能说「四支柱的权重是按 T+5 拟合的」

因为 `evolve` 拟合的是 **blogger / strategy / senti / engine 四路信号**，不是四支柱。
其中只有 `engine` 一路**间接**含支柱输出（主引擎交叉里会出现「四支柱·policy_funnel」这类标签），
但 `engine` 一路 ≠ 四支柱之和：它还混了每日预测、共振等别的来源，且四支柱之间不独立加权。
**"engine 一路含支柱信息" 推不出 "四支柱的权重是这么定的"。**

### 3. 正确的表述（照抄，别再改写）

> **权重拟合口径是 T+5，落在四支柱已衰减为负的持有期区间内。**

对应的实证（生产 `pillars_daily.state_json.per_pillar`，`policy_funnel` 一柱）：

| 周期 | avg_alpha |
|---|---|
| T+1 | **+0.512%** |
| T+5 | **−1.776%** |
| T+10 | **−4.267%** |

翻译：这根支柱的选股在 T+1 是正的，到 T+5 已经翻负、T+10 继续恶化。
而 `evolve` 恰好在 **T+5** 这个点上学权重 —— 也就是说，**权重是在支柱已经开始衰减的持有期上学出来的**。
这是一个**需要披露的口径事实**，不是一个可以顺手"修正"的 bug（改拟合周期＝改行为，未获授权，见 §4）。

### 4. 本轮**不做**的事（登记，避免下次误以为漏做）

1. **不把拟合周期改成 T+1**。`per_pillar` 显示 T+1 更好看，但改成 T+1 拟合会换掉整套 per-state 权重，
   等于线上行为改变，必须先有样本外对照（谁也不知道 T+1 拟合的权重在 T+5 上还剩多少）。
   本轮只做**埋点披露**（`evolve.FIT_HORIZON`、`selfpick.snap.fit_horizon / pick_horizon / horizon_match`），
   **不改取权重的行为**。
2. **不在报告里写"四支柱的权重是按 T+5 拟合的"**。按 §3 的表述写。
3. **`per_pillar` 的 `"20"` 档全 `n=0` 不是 bug**：`n=0` 已带 `unmatured` 标记
   （`pillars.py:1157-1161`），含义是"结算窗口还没走完"，不是"零样本"。
   已核实**前端零消费方**（`grep per_pillar` 只命中写入那一行），故加标记而非删除。

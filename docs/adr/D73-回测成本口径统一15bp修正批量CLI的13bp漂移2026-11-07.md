## D73 回测成本口径统一为 15bp（修正批量 CLI 的 13bp 漂移）（2026-11-07）

- **背景**：P4 已将回测成本收敛为**单一事实源** `viewer/kernel/params.py: BACKTEST_FEE_ROUNDTRIP = 0.0015`（即 15bp = 双边佣金 5 + 卖出印花税 5 + 滑点 5），`viewer/kernel/cost_basis.py` 也据此向 `/api/cost_basis` 返回「回测口径 15bp」。但三个**批量回测入口**未同步：
  - `tools/router_backtest_all.py: --cost-bp default=13.0`（且汇总表文本硬编码「已扣 13bp」）；
  - `tools/router_backtest_oss.py: run_oss(..., cost_bp: float = 13.0, ...) 与 --cost-bp default=13.0`；
  - `tools/score_ledger.py: 报告文本硬编码「已扣 13bp 双边成本」。
  
  单工具 CLI `tools/router_backtest.py` 早已正确引用 params（`DEFAULT_COST_BP = round(_KERNEL_PARAMS.BACKTEST_FEE_ROUNDTRIP * 10000.0, 4)` → 15bp）。因此 zQv2rP（批量跑 kline 组）实测打印「成本=13bp」，与内核口径漂移——正是 `backtest_core.py` docstring 预警的「13bp vs 15bp 口径漂移」未彻底收口。

- **结论（2026-11-07 重构收尾时修正）**：
  - **事实**：内核回测成本本就是 15bp（`BACKTEST_FEE_ROUNDTRIP = 0.0015`），从未改过；这一条只是把**漂移的批量 CLI 对齐到已有内核值**，不是另立口径。
  - **判断**：三个批量入口的 `--cost-bp` 默认值改为 `round(_P.BACKTEST_FEE_ROUNDTRIP * 10000.0, 2)`（单一事实源，将来内核调成本 CLI 自动跟随）；`router_backtest_all.py` 的汇总表文本与 `score_ledger.py` 的报告文本改为动态引用该值，不再写死数字。`--cost-bp` 仍保留手动覆盖能力（对某工具单独用不同成本时可用）。

- **影响模块**：`tools/router_backtest_all.py`（默认 + 汇总文本）、`tools/router_backtest_oss.py`（默认 + run_oss 默认值）、`tools/score_ledger.py`（报告文本）。

- **验证**：`python tools/router_backtest_all.py --help` 显示「--cost-bp ... 默认取内核统一值 15bp（params.BACKTEST_FEE_ROUNDTRIP）」；回归套件 96 测试全绿（tools/ 改动未被单测直接覆盖，但 import 与 CLI 解析已验证）。

- **推翻条件**：若内核 `BACKTEST_FEE_ROUNDTRIP` 调整，CLI 自动跟随，无需改本条目；若业务上确需对某工具组用不同成本，用 `--cost-bp` 显式覆盖并注明原因即可。

## D69-勘误 · 读了 FinRL 源码之后，D69 的三条论断作废（2026-11-03 当日）

进哥当场质疑：「你没有找到他的这个根据或者是方法，然后就妄下定论了。」
质疑成立。我随后通过 GitHub 连接器读了 `AI4Finance-Foundation/FinRL` 的源码
（`finrl/config.py`、`finrl/meta/env_stock_trading/env_stocktrading.py`、
`finrl/meta/preprocessor/preprocessors.py`），确认 D69 有三处硬错：

**1. 我测的不是 FinRL 的特征。** 它真正的特征清单写死在 `config.py :: INDICATORS`，
共 8 个 stockstats 指标：`macd / boll_ub / boll_lb / rsi_30 / cci_30 / dx_30 /
close_30_sma / close_60_sma`。我在 `exp_rl_probe.py` 里手搓的 12 维（动量、波动率、
均线偏离、量比……）跟它**一条都不重合**。所以"FinRL 学不到东西"这个结论，
说的是我自己造的特征，不是它的。

**2. 我测的任务也不是 FinRL 的任务。** 它的 state 是
`[现金] + 全部收盘价 + 全部持仓股数 + 8×N 个指标`，action 是 `Box(-1,1,shape=(N,))`
的**连续股数**，reward 是 `end_total_asset - begin_total_asset`（美元绝对值 × scaling）。
它是**N 只票的组合分配**；我做的是**单只票的三档择时**。问题都不一样。

**3. "美股口径、A 股拆不过来"是错的。** 它自带 `meta/preprocessor/tusharedownloader.py`
（Tushare，中国数据源），`config.py` 里明确列了 `TIME_ZONE_SHANGHAI`，
注释写着「Hang Seng HSI, SSE, CSI」。它本来就是支持 A 股的。

**重做的实测（`tools/exp_finrl_indicators.py`，用 stockstats 原库算它自己的指标）**

300 只票、520 日训练 / 250 日样本外，归一化后逐维过三期门禁：

| 维度 | 训练期 IC | 测试期 IC | 符号 |
|---|---|---|---|
| rsi_30 | −0.0614 | **−0.0756** | 同号 |
| close/SMA30−1 | −0.0611 | −0.0665 | 同号 |
| close/SMA60−1 | −0.0594 | −0.0646 | 同号 |
| boll_lb/close−1 | +0.0614 | +0.0626 | 同号 |
| macd/close | −0.0543 | −0.0615 | 同号 |
| cci_30 | −0.0538 | −0.0591 | 同号 |
| 布林%B | −0.0535 | −0.0546 | 同号 |
| boll_ub/close−1 | +0.0193 | +0.0266 | 同号（未过 IC 线）|
| dx_30 | −0.0300 | +0.0006 | **翻号** |

**训练期过 6/9、测试期过 7/9，且 7 维符号一致。** 也就是说：FinRL 想要的这批数据因子，
我们自己完全扒得出来，而且在 A 股上有预测力。**D69 里"算法层不拆"的依据因此不成立了** ——
输入有信号，那我那次 DQN 没学出来，问题在 RL 的实现/设定，不在特征。
这条待重做，不能拿旧结论当依据。

**turbulence 那条也要改。** 第一版我喂了 300 只票进 252 天窗口，300×300 协方差秩最多 252，
欠定，pinv 把数值放大到 9e12，是纯噪声。照它原版的道指 30 只量级重算后（30 只 / 50 只
两档，可用 596 天）：

- turbulence 与次日全市场等权收益的 Rank IC = **+0.040（30 只）/ +0.066（50 只）**
- 95 分位以上的 30 天：次日平均 **+0.913%**；其余 566 天：**−0.007%**

**方向和 FinRL 的用法正好相反**：它的逻辑是「turbulence 超阈值就清仓躲风险」，
但在我们这段 A 股样本里，恐慌日之后是**反弹**。所以这块的可搬运部分是
「马氏距离做市场状态开关」这个机制，**不是它的阈值方向** —— 照抄会做反。
样本只有 30 个事件，证据强度弱，需扩样本复核后才能用。

**保留的结论**：`tools/exp_rl_probe.py` 里那三条防作弊纪律（严格 T+1 / 特征只用 t 日及以前 /
一字板不成交）与三档仓位环境仍然是对的，作为回测公共口径继续用。

### 1.2 待改（[判断]）

1. **首屏前置噪音 250px**：107px 固定栏 ＋ 约 44px 提示语 ＋ 71px 统计条。1080 高屏幕下，真正内容只剩约 830px。

3. **左栏底部入口易误认**：`知识库 v5.0 · 1004 节点` + `立即吸取` 固定在导航区底部，视觉上与导航项同级。

### 1.3 「顶部横向导航栏」的现状（需对齐）

## 3. 回测页面专项（问题最集中）

### 3.1 事实

数据规模（`GET /api/kb/doc?key=zdx_stock`）：**3 张表 / 33 条策略**。

| 表 | 列数 | 行数 | 备注 |
|---|---|---|---|
| 表 B-1 基础技术指标/突破/回调策略 | **12** | 18 | 无「来源博主」列 |
| 表 B-2 短线游资风格策略 | 10 | 7 | 无「来源博主」列 |
| 附录B-3 v5 新增 8 个策略 | **13** | 8 | 有「来源博主」列 |

真实浏览器实测（1440 / 1100）：

1. **策略名是程序标识符**：`MA5_cross`、`MACD_fast_6_7_4`、`breakout_20d_v1.5`、`second_board_dragon`、`hui_guo_rou`（拼音）、`strategy_2560`、`weak_to_strong`。
   而**表 B-3 用的是中文名**（`树干理论回踩（涅盘重升）`）→ **同一份知识库两个表风格完全不一致**。
2. **数字列右对齐率 0/28** —— 12 列百分比表格全部左对齐，无法纵向比较（截图 `ux_bt_1440.png`）。
3. **数值着色语义相反**：`平均亏损 1.82%` 存成正数 → 被 `pctCls()` 按「正数 = 涨」染成**红色**；`平均最大回撤 -40.6%` 染绿。**「亏损」列用涨色，语义正好相反**。
4. **1100px 下宽表右侧被截断**：表 B-1 内容 984px / 视窗 784px，右侧「平均年化 / 平均最大回撤 / 评级」3 列完全不可见；表 B-2「评级」只剩半个 badge。有滚动条但**无「可横向滚动」提示**。
5. **表 B-3 的「来源博主」列内容错位** —— 已核对原始 md：

   ```
   | 策略名称 | 来源博主 | 测试股票数 | ... |
   | 树干理论回踩（涅盘重升） | trunk_pullback | 16 | 45 | ... |
   ```

   **上游 md 本身即如此**：列名叫「来源博主」，装的是策略 ID。**不是解析器的问题**，无法在程序侧纠正，只能标注或在上游修。
6. 无排序、无合计、无最优/最差高亮；表头写「18 个策略」，但没有任何方式把这 18 条按胜率排开。

### 3.2 [判断] 重构方案

- **摘要 + 明细两层**：策略卡显示「中文名 · 博主 · 评级」+ 4 个核心指标（胜率 / 盈亏比 / 总收益 / 交易数）；点开才展开其余 8 列。
- **建中文名映射表**（约 33 条），落 `config/strategy_names.yaml`；解析层套用，缺映射时标「名称待补全」而非直接露键名。
- **数字列**：`text-align:right` + `font-variant-numeric: tabular-nums`。
- **语义配色拆分**：`pctCls()` 增加「列语义」参数 —— `平均亏损 / 平均最大回撤 / 最大回撤` 一律走跌色，不参与「正 = 涨」判定。
- **列序统一**：三表合并展示时按 `策略 / 博主 / 交易数 / 胜率 / 盈亏比 / 收益 / 回撤 / 评级` 固定顺序，缺列留空并标注。
- **滚动提示**：`.kb-scroll` 右侧加渐隐边 + 「← 左右滑动看全部 13 列」提示。

        每套主题各给一组值 → 143 处硬编码收敛到 0

## 7. 本轮审计的自审（我在本次犯的错，均已修正）

1. **探针截图被 topbar 的 `position:sticky` 骗过**：我一度判定「9 张统计卡不见了」，实测 DOM 后确认卡在（`display:grid`、9 个子元素、top=190）。根因是页面停在上一段的滚动位置，而 sticky 顶栏照常可见 → 截图"看起来正常"。已在 `shot()` 里强制 `scrollTo(0,0)`。
2. **回测断言写反**：原断言要求「每张表都必须溢出滚动容器」——但窄表放得下是好事。已改为「每张表都在 `.kb-scroll` 内」+「放不下的表确实可滚」。
3. **首次硬编码色统计正则漏了同行多变量**：`^\s*(--x):` 只匹配行首变量，得出「每套主题仅 4 个变量」的错误结论；已改用单行多变量解析，确认实际 17 个且 4 套完全对齐。
4. **四个并行调查员全部因账号级 429 失败**（1 秒即退出，无产出），本报告由我直接完成，未代其编造内容。

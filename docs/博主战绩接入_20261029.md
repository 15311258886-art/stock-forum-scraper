## 二、⑥ 做了什么

### 新增文件

`viewer/blogger_score.py` —— 博主战绩评分层，产出 `blogger_score` 表：

| 列 | 含义 |
|---|---|
| `n_stocks` / `n_days` | 原始推荐条数 / 独立观测数（博主×推荐日） |
| `med_per_day` | 日均推荐只数中位数（识别批量扫单） |
| `edge_mean` / `edge_med` | 日度超额均值 / 中位数（百分点，已减基线） |
| `edge_shrunk` | 收缩后超额 `edge × n/(n+8)`，用于定档 |
| `t_stat` | 按日度观测算的 t 值 |
| `win_days` | 超额 > 0 的交易日占比 |
| `edge_h1` / `edge_h2` | 前后半段日均超额 |
| `stab` | ok / bad / unstable / insufficient |
| `grade` | A 可参考 / B 观察 / C 劣势 / D 样本不足 |
| `cred` | 信誉系数 0.5~1.5，供 `resonance` 使用 |

### 修的三个方法学缺陷

**1. 用绝对收益定档 = 把「大盘跌」算成「博主无能」**

原 `resonance.py::_blogger_credibility`：

```python
cred = 1.0 + (a5 / 100.0) * 3.0 + (win5 - 0.5) * 1.5     # a5 = AVG(r5)
```

实测 `blogger_perf` 的 r5 均值 **-3.29%**、兑现率 **29.8%**（n=954）。但样本期
2026-08~10 全市场是弱势（同期 T+5 基线为负），所有博主一起吃亏。旧公式把全员
打到 **0.500 ~ 0.863**，等于集体禁言。

现在先算「推荐日全市场 T+5 等权均值」作基线，个股 r5 减基线得超额。

**2. 独立观测不是「博主×股票」**

实测同一博主单日最多推荐 **56 只**（土豆看财报 2026-10-19）。同一天推的所有票
共享同一市场因子，按「博主×股票」计样本会把 n 从几十吹到 1000+。现在一律先按
**(博主, 推荐日)** 聚合成 1 个观测。

**3. 小样本直接定档**

1 条记录的博主也会被算出 ±1.5 系数。现在：`shrunk = edge × n_days/(n_days+8)`，
且评级要求 `|t| ≥ 2`，`n_days < 8` 直接判 D（中性 1.0）。

**额外加了一道证据强度折减**：`cred = 1 + shrunk × 0.15 × min(1, |t|/2)`。
只按 shrunk 加权是不够的——所有博主 |t| < 1.2 时直接乘 0.15 会给出 +27% 的加成，
等于用噪音放大仓位。折减后无人显著 → 系数自动退回 ≈1.0。

### 结果

样本期 2026-08-14 ~ 2026-10-22，基线由 **52 个交易日**自算，15 位博主、898 条有效样本：

| 博主 | 独立天数 | 日均只数 | 日度超额 | 收缩超额 | t 值 | 评级 |
|---|---|---|---|---|---|---|
| BRTV 天下财经 | 3 | 1.0 | +14.29 | +3.90 | 1.11 | D |
| 独股九剑 | 24 | 5.0 | +2.40 | +1.80 | 0.77 | B |
| A股短线女王-指南针 | 9 | 5.0 | +2.81 | +1.49 | 0.99 | B |
| A股化债人 | 14 | 4.0 | +1.03 | +0.66 | 0.45 | B |
| A股邵帮主-指南针 | 16 | 9.5 | +0.12 | +0.08 | 0.09 | B |
| 土豆看财报 | 8 | 12.0 | -0.89 | -0.44 | -0.49 | B（一致为负） |
| 交易修行 | 5 | 3.0 | -3.32 | -1.28 | -1.17 | D |

**关键结论：没有任何一位博主通过显著性检验（最高 |t| = 1.17 < 2），
有效独立窗口仅 10.4 个（52 ÷ 5）。**
评级全部落在 B/D，信誉系数收窄到 **0.984 ~ 1.11**（旧口径 0.500~0.863）。

### 一个反直觉的发现：前视偏差是反的

`blogger_perf` 的基点取法是「≤ rec_date 的最后一个交易日」，所以周末发布的
推荐用上周五收盘起算 —— 那一刻消息还没出，**实际买不到**。原以为会因此高估收益，
实测相反：

- 交易日发布 712 条，平均超额 **-0.733 pt**
- 非交易日发布 185 条，平均超额 **-2.199 pt**
- 前视偏差 **-1.465 pt**（负向）

所以 r5 口径不构成虚高；非交易日发布的多是周末复盘、质量更差。

## 三、为什么没有新开 predictor 第 13 路信号

`predictor.py` 现有 12 路（tech / holders / ann / desk / inst / policy / board /
sentiment / overseas / follow / extref / lhb），**没有 blogger 路**。本轮没有加：

- 全部博主 |t| < 1.2，加进去的权重只能由先验 × 覆盖度撑起来，本质是噪音；
- 接入点在 `resonance` 已经通了：`blogger_score.cred` → `_blogger_credibility`
  → `_pull_blogger` 的 `raw = 50.0 × cred` → 「博主共振」面板；
- 与其多一路低质量信号，不如等样本攒到 20+ 个独立窗口再评估。

## 六、遗留

- 样本期只有 52 个交易日，有效独立窗口 10.4。要给出「谁可跟单」的结论，
  至少需要攒到 20 个窗口（约 100 个交易日 / 4~5 个月）。
- `extref_signals` 412 条里 **404 条是东财人气榜的 rank 记录、direction 全为中性**，
  真正带「看多」观点的只有 8 条。想把它当观点源使用，得先扩充采集面，不是算法问题。
- `blogger_reco` 与 `blogger_perf` 同为 1008 条、15 人，去重后实际覆盖的股票数偏少，
  同一博主同日推 50+ 只的情况普遍，选股信息量结构性偏低。

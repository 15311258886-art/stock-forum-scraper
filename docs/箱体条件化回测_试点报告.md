# 箱体底部 · 条件化回测试点报告

日期：2026-11-05　｜　脚本：`tools/cond_box_backtest.py` + `tools/cond_box_market_base.py`
数据：`data/kline_daily.db`（前复权）　｜　产物：`viewer/logs/cond_box_20261105_long.json`

---

## 1. 为什么换口径

上一轮所有回测用的都是**绝对超额**：

```
个股 H 日收益 − 同日全市场等权 H 日收益 − 0.25%
```

这个数回答的是「这票比随便买一只强吗」。但箱体类工具**不是这么用的**。它的真实链路是：

```
全市场 5300 只  --箱体门槛-->  约 300~600 只正在箱体里运行的票  --工具-->  其中位置低的
        （这一步是前置池，工具管不着）              （这一步才是工具干的事）
```

所以拿「比全市场强不强」去判它，等于拿短跑成绩去评价一个跳高运动员。它的职责是**在一个已经被前置条件筛过的池子里，把该挑的挑出来**。

换成两个数：

| 指标 | 问的问题 | 用途 |
|---|---|---|
| **池内区分力** = 触发组 − 同池未触发组 | 池子里，被工具点中的那批，是不是真的更好？ | **主判据** |
| 池 vs 全市场等权 | 这批票整体比随便买强吗？ | **只作背景**，见 §6 的口径警告 |

同一天、同一池、同一持有期，两组只差「触发 / 未触发」一个变量。市值、行业、行情、流动性全部自动对齐——这是**天然的风格中性**。

## 2. 怎么测

| 项 | 取值 |
|---|---|
| 窗口 | 2012-01-04 ~ 2026-11-04（**3598 个信号日**，14.8 年） |
| 前置池 | 通过 `viewer/universe_box.py` 的一级+二级门槛 |
| 触发组 | 池内 `pos ≤ 1/3`（箱体下三分之一） |
| 对照组 | **同一天、同一池内 `pos > 1/3`** |
| 持有期 | T+20（对照）/ T+60 / T+120（箱体的真实尺度） |
| 成本 | 0.25% 往返，两组同扣，差值中抵消 |
| 样本 | 扫描 5263 只票，**1,028,586 条**箱体池记录，日均池 291.7 只 |
| 显著性 | NW t（lag=H/5，修正重叠）+ **非重叠抽样 t**（每 H 天取一个，窗口不重叠） |
| 稳健性 | 6 段分段，逐段贴同区间大盘涨跌标签 |

### 门槛逐条核对（与 `viewer/universe_box.py` 对齐）

| 门槛 | 线上 | 本脚本 | 一致 |
|---|---|---|---|
| MIN_BARS / BOX_WIN | 750 / 750 | 750 / 750 | ✅ |
| MIN_AMOUNT_AVG | 3.0e7（近 250 日 close×v） | 同 | ✅ |
| PCT_MAX | 30.0（`_pct_rank`: `sum(v<=cur)/n*100`） | 同 | ✅ |
| CV_MAX | 40.0（`statistics.pstdev`） | `np.std`（ddof=0，population） | ✅ |
| SLOPE_MAX | 18.0（`num/denom*252/mean*100`，`mx=(n-1)/2`） | 同式向量化 | ✅ |
| TOUCH_MIN | 2（收盘落箱顶/箱底 3% 带） | 同 | ✅ |
| DWELL | ≥15%，近 250 日落下 1/3 占比 | 同 | ✅ |
| `box_low <= 0` → None | 有 | 首轮漏，次轮补 | ⚠️ 见下 |
| `min_years=0.5` | 有 | 未实现 | ✅ 不绑定（见下） |

- **`box_low<=0`**：首轮（`cond_box_20261105.json`）漏了这个判断，次轮已补。全库 `c<=0` 只有 **401 / 18,543,542 = 0.002%**，且要恰好落进某只票的 750 根窗口才起作用，影响可忽略。正式结果用次轮。
- **`min_years`**：`box_years = len(win)/252`，而 `win` 恒为最后 750 根 → 恒 = 2.98 年，`0.5` 永远不触发。不构成偏差。

### 过程中修掉的两个错（都记在这里，不藏）

1. **SQL 别名冲突**：`SELECT d, COUNT(*) c ... HAVING c>=3000`，`c` 被 SQLite 优先解析成 kline 的**收盘价列**，变成「收盘价 ≥ 3000 元」，一个信号日都取不到。改成 `COUNT(*) >= 3000`。
2. **绝对门槛误杀早年**：`COUNT>=3000` 这种写法在 2016 年之前不可能满足（2010 年全市场 1953 只、2016 年底 2879 只），实测把「2012 起」的窗口悄悄砍成「2017 起」。改成**相对门槛**：当天票数 ≥ 前后 120 个交易日最大票数的 60%。
3. **负索引静默污染**：`sig_pos - 749` 在 `sig_pos < 749` 时为负，numpy 会从数组末尾绕回来，等于**用未来数据算箱体**。已加 `pos_of[d] >= BOX_WIN-1` 剔除。

## 3. 主结果：池内区分力

14.8 年、103 万条样本：

| 持有期 | 有效日 | 底部组 | 同池其余 | **差** | NW t | 非重叠 n / 差 / t | 差>0 天数 |
|---|---|---|---|---|---|---|---|
| T+20 | 755 | +0.707% | +0.743% | **−0.036pp** | −0.14 | 38 / +0.44 / 0.66 | 52.7% |
| T+60 | 730 | +0.961% | +1.369% | **−0.409pp** | −0.58 | 13 / +0.58 / 0.39 | 46.2% |
| T+120 | 729 | +4.015% | +5.609% | **−1.594pp** | −0.88 | 7 / −5.85 / −0.86 | 44.0% |

三行 |t| 全部 < 0.9，且 T+60 的 NW t（−0.58）与非重叠 t（+0.39）**符号相反**——这是噪声的典型特征，不是弱信号。

> **分辨率声明**：T+120 的 SE ≈ 1.8pp。也就是说，**如果箱体底部真有 4pp 以上的优势，这个样本能看见**；没看见。而观测到的 −1.6pp 本身也分辨不清是不是 0。所以正确的说法不是「箱体底部有害」，而是「**在这 14.8 年里，箱体底部相对同池其他票没有任何可测出的优势**」。

### 3 年 vs 14.8 年的对比（说明为什么必须拉长）

| 窗口 | T+120 差 | 说明 |
|---|---|---|
| 2023-11 ~ 2026-11（3 年） | **+1.894pp** | 靠 2024H2~2025H1 一段反弹撑起来的 |
| 2012-01 ~ 2026-11（14.8 年） | **−1.594pp** | 符号翻转 |

**只跑 3 年会得出相反的结论。** 这就是当初「最近市场不好就全废了」的具体形态。

## 4. 分段：没有稳定的适用行情

T+120 逐段（每段约 121 天，`同期大盘` = 同区间全市场等权涨跌）：

| 区间 | 边缘 | 同期大盘 |
|---|---|---|
| 2012-02 ~ 2019-03 | +0.12pp | +79.4% |
| 2019-03 ~ 2019-09 | −8.73pp | −5.9% |
| 2019-09 ~ 2022-11 | −9.31pp | +35.0% |
| 2022-11 ~ 2024-10 | **+13.25pp** | −4.8% |
| 2024-10 ~ 2025-04 | +0.38pp | +14.4% |
| 2025-04 ~ 2026-02 | −5.18pp | +44.3% |

两种情况都试了：既不是「只在上涨市有效」（2019-2022 大盘 +35% 却是 −9.3pp；2025-2026 大盘 +44% 也是 −5.2pp），也不是「只在下跌市有效」（2019 年大盘 −5.9% 是 −8.7pp；2022-2024 大盘 −4.8% 是 +13.2pp）。**方向与大盘涨跌不构成稳定关系**，段间摆幅 22pp。

结论：不存在「箱体底部在某些行情下可用」这种退路。

## 5. 与「工具真实行为」的对应关系（重要）

`toolbox.py:1491` 里 `box_bottom` 的默认参数是 `pos_max = 1.0` ——**它默认根本不要求在箱体底部**，只要过箱体门槛就收。所以：

| 线上实际行为 | 对应本报告 | 结论 |
|---|---|---|
| `box_bottom` **默认参数**（pos_max=1.0） | 就是「池」本身 | 见 §6 |
| `box_bottom` **收紧**到 pos_max=1/3 | 池内再切下 1/3 | 池内区分力 = 0（§3） |

也就是说：**「在箱体票里挑谷底的」这个声明，14.8 年数据不支持。收紧参数只会让池子变小，不会让结果变好。**

## 6. 池 vs 全市场：这个数**不能用来判工具**

| 持有期 | 池均值 | 全市场等权 | 超额 |
|---|---|---|---|
| T+20 | +0.710% | +1.253% | −0.543pp |
| T+60 | +1.046% | +3.016% | −1.970pp |
| T+120 | +4.211% | +8.086% | −3.875pp |

看起来很难看，但**不能据此判定箱体工具是负的**。原因：池子要求日均成交额 ≥3000 万且在 750 日低位，天然偏向中大盘；而同期 A 股等权指数被小盘/微盘拉动（此前风格中性化实测：换手五分位 Q5−Q1 在 T+20 = **−2.19pp**，小盘完胜）。池跑输等权市场，很大一部分是**风格暴露**，不是工具选错了票。

**要判「池子本身值不值得看」，必须先做风格中性化**（按市值/换手分层后再比）。这一步本轮没做，所以 §6 只作背景，**不作结论**。

## 7. 这次试点真正拿到了什么

1. **方法成立**：条件化回测能算出一个旧口径永远算不出的数——「工具在自己适用条件下的池内区分力」。同池同日对照，风格自动中性。
2. **一个确定的负面结论**：箱体底部（`pos ≤ 1/3`）的池内区分力为 0。这是旗舰级中线工具的核心声明，14.8 年、103 万条样本，t 全部 < 0.9。
3. **一个方法学结论**：持有期决定需要多少历史。6 个月持有期 + 3 年数据 = 最多 6 个独立样本，**根本不够**。以后所有长持有期工具的回测窗口必须 ≥10 年，否则不要下结论。这一点直接改写了后面 30 个工具的回测设计。
4. **一个待补的口径**：池类工具（箱体、质量、机构建仓）的「池 vs 市场」必须中性化后才能看，否则会重复犯「拿错尺子」的错。

## 8. 局限（明确列出，不含糊）

- **幸存者偏差**：库里有 568 个代码末年 < 2026（如 000003），退市票**部分**在内，但不是完整退市库。14.8 年的多头回测因此偏乐观——这只会让「箱体底部无效」的结论更稳，不会更弱。
- **前复权口径**：早年前复权数据质量未逐年核过（`audit_hfq_gap.py` 只核了 kbase 的 hfq 机械缺口）。2012-2016 段若存在除权处理错误，会加噪声。
- **未测复合打分**：本报告只测了 `pos ≤ 1/3` 这个二值触发。`box_bottom` 的 score 是 `pos/dwell/regular/touch` 的加权（W_POS=0.45 等）。理论上一个线性组合有可能从「各分量都无效」里造出有效——但 pos 贡献 45% 权重且已被证否，其余分量都是「箱体像不像」的描述，不构成方向预测。**要不要补测 score 前 N 名，等结论确认后再定。**
- **停牌/涨跌停未做可交易性处理**：前复权序列直接算收益，未剔除一字板无法买入的日子。这对池内两组是同样的影响，不改变比较方向。

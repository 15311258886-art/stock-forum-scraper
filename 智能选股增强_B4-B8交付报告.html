三、怎么用

1. 打开查看器 → 进入「智能选股」结果页。
2. 结果上方出现一排新按钮：说人话选股输入框 + 生成筛选 / 估值分位 / 回测 / 题材 / ⚙ 设置。
3. 点「估值分位」「回测」「题材」直接看弹层结果；点「⚙ 设置」填 DeepSeek Key（见下）。
4. 顶部输入框写自然语言 → 「生成筛选」自动转条件并刷新选股。

四、DeepSeek 接入 · 三步

1
建 Key：登录 platform.deepseek.com → API Keys → 创建密钥，复制 sk-...。
2
充值：在开放平台单独充值（⚠️ 网页 会员 ≠ API 余额，会员不能当 API 调用费；要能调模型必须有 API 余额）。
3
填设置：查看器选股页点「⚙ 设置」→ 粘贴 Key → 保存。Key 仅写入本机 viewer/.deepseek_key，不上传、不经浏览器、不经 WorkBuddy 会员账户。填一次即可，之后「说人话选股」直接生效。
关键澄清：WorkBuddy 的会员/积分不能给这个独立桌面 app 当 DeepSeek 扣费通道——这是两套独立系统。本软件只认你自己的 platform.deepseek.com API Key + 余额。

用托管 Python 直接调用 screener_extra 各函数（沙箱无第三方包→走 mock 兜底，与线上一致）：估值分位 pe_pct=0.592 / 回测 n=2 胜率 100% / 题材 8 个 / 杜邦 ROE 拆解 / 自然语言未配置快速返回「未配置…」/ Key 落盘读回 / K线 mock 60 根。

✅ 端到端脚本已修正（verify_screener_enh3.cjs v5）

修复了 v1/v2 因请求拦截吞掉 POST body 导致设置/NL 失败的问题：仅拦截基础 /api/screener GET 注入 mock，其余含所有 POST 全部放行并保留 body。在你本机能正常启动 server.py 的环境下可一键跑通全链路。

六、边界与注意

  • 沙箱/无网环境：估值、回测、题材、杜邦、K线走 mock 演示数据；在能联网 + 能 pip install akshare baostock pandas 的本机运行 viewer/server.py 时自动切换真实数据。费用：底层数据（AkShare/Baostock）本身免费，无需为数据付费。
  • DeepSeek 调用：按 token 计费，从你自己的 API 余额扣；建议随用随调，不要高频刷。
  • Key 安全：明文存于本机 viewer/.deepseek_key，仅本机服务读取，不上云。
  • 改完后端须重启：server.py 改完要重启才生效（前端刷新救不回后端）。

二、BUG与问题清单（按优先级）

P0 东财push2资金流接口全系列不可达

现象：个股资金流、主力净流入排行、板块资金流（东财源）全部返回空数据，接口耗时3-14秒后失败。

根因：东财push2系列接口（ulist/clist/push2his/fflow）从本机直连和代理均被RST断开，DNS正常，疑似本机出口被限流或接口下线。

影响：资金流向面板「主力净流入排行」「个股资金流」两块无数据，用户体验为空页面。

修复建议：

  • 快速修复（10行代码）：失败时面板显示明确提示「东财资金流源今日不可达，请查看板块资金流标签」，不要空转。
  • 根治：切换新浪/腾讯资金流接口作为兜底数据源。
  • 负缓存：失败后30分钟内直接返回空结果+错误标记，避免每次请求都等3-14秒。

P0 股票名称抽取覆盖率仅27%

现象：3067条帖子中仅27%能识别出提到的股票，「当前讨论股票」面板只显示70只票。

根因：抽取链路只做了「代码识别」（如"买600519"），未做「中文名→代码映射」（如"买茅台"）。

影响：大量热门股（美的、格力、宁德时代、茅台、中国平安等）在讨论列表中不可见，净漏151只票。

修复建议：在现有抽取函数中增加中文名匹配逻辑（映射表已有5596条），重跑一次全量回填，讨论股票数从70只提升到221只。

P0 换手率Top接口冷启动112秒

现象：首次打开「换手率龙头」接口耗时112秒，第二次缓存后2.6秒。

根因：K线缓存（kline_cache.json 7.35MB）按"整天"判定新鲜度，跨日即触发5500只股票全量重补。

影响：每天第一次打开选股类页面白屏2分钟以上，用户以为卡死。

修复建议：缓存按"最后有效交易日"分片，只补增量；或失败接口记入30分钟冷却表。

P1 服务不常驻，关窗即退出

现象：关闭桌面窗口后，8765端口服务进程也随之退出，下次打开需重新启动后端。

根因：desktop_app.py结尾用os._exit(0)兜底杀进程。

影响：想保持后台运行随时看盘的场景不友好。

修复建议：增加"最小化到托盘"选项，窗口关闭时可选"退出程序"或"最小化到托盘"。

P1 static目录大量备份文件冗余

现象：app.js 有20+个.bak备份，app.css有15+个.bak备份，占用空间且影响目录整洁。

影响：无功能影响，但部署/打包时体积臃肿，排查问题时容易混淆版本。

修复建议：定期清理.bak文件，只保留最近3个版本；或移到专门的backup目录。

P1 板块名称点不进去（死胡同）

现象：「板块动向」「板块资金流」面板中，板块名称只是文字，点击无反应，无法查看板块详情。

对标：东方财富点板块名可直接进入板块详情页（成分股/板块K线/估值分位）。

修复建议：新增板块详情面板，展示：①成分股列表（可排序）②板块K线 ③板块内资金对比 ④板块估值分位。

P2 个股诊断第四层下钻缺失

现象：估值因子、财务指标、公告、研报均为"展示即止"，点击无法查看详情。

对标：东方财富F10有完整的公司概况/财务分析/股东研究/融资融券/北向资金/机构调研等。

修复建议：逐步补充F10深度：财务趋势图→股东研究→融资融券→北向资金→机构调研。

P2 无自然语言选股/AI问答

现象：选股只能从预设标签页切换，无法输入条件（如"市盈率低于20的新能源股"）。

对标：同花顺问财支持自然语言查询，东财妙想支持AI问财报。

修复建议：二期接入LLM，支持自然语言转选股条件、财报AI摘要。

💡 核心差异化优势（与主流软件错位竞争）：
  • 淘股吧/游资舆情聚合：这是同花顺/东财没有的垂直特色——你追踪的是"大V怎么说、游资怎么买"，而不是传统行情软件的"价格怎么动"。

四、优化路线图建议

🔥 第一阶段：快速修复（1-3天，立竿见影）

  • 资金流空态提示：东财源失败时显示明确文案，不要白屏等待（10行代码）
  • 负缓存机制：失败接口30分钟内直接返回缓存，避免用户每次等10秒
  • 中文名抽取补全：重跑股票名称识别，讨论股票从70→221只
  • 清理备份文件：删除static目录下20+个.bak冗余文件
  • 换手率缓存优化：K线缓存分片，冷启动从112s降到3s

📈 第二阶段：体验提升（1-2周，缩小差距）

  • 板块详情页：补全板块→成分股→个股的完整下钻链路（P0痛点）
  • 个股诊断第四层：补充F10核心字段（财务趋势、股东、融资融券）
  • 资金流多源兜底：东财挂了自动切新浪/腾讯源
  • 托盘最小化：关闭窗口可选最小化到系统托盘，保持后台运行
  • 慢接口异步化：诊股/选股类接口分阶段返回，先给用户看到骨架再加载数据

🚀 第三阶段：差异化深化（1-2月，建立壁垒）

  • 博主胜率排行榜：按荐股收益率给博主排名，识别真正的大V
  • 牛散跟踪预警：知名牛散新建仓/加仓自动推送提醒
  • 策略回测实验室：把"游资+博主共识"做成可回测的策略信号
  • 产业链图谱：点个股→上下游受益股联动分析
  • AI问答：接入LLM，支持"今天哪个板块游资买最多？""茅台有什么博主在推？"

五、总结

链路健康度：✅ 优秀 — 67个API仅1个超时，前端资源100%正常，无阻断性BUG。

核心问题：不是功能断了，而是两个"数据源不可达"导致的体验空转（东财资金流、股票名称抽取），加上几个首屏慢接口拖慢体验。

产品定位：这不是一个"迷你版同花顺"，而是一个垂直的游资/大V舆情分析终端——你的护城河是"人"（谁在买、谁在推、胜率多少），而不是"价"（K线、指标、技术分析）。优化方向应该继续加深这个差异化，而不是去补全同花顺已经做了20年的行情功能。

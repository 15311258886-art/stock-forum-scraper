一、回测注意事项清单（从公开资料扒的坑，已逐条落地护栏）

A 类 · 数据陷阱

已落地幸存者偏差：只回测"现在还在上市"的股票，会系统性高估。→ 报告标注 survivorship_note，且样本外仅用当时已上市标的。
已落地前视偏差：用"未来才知道"的数据下注。→ 信号由月末收盘生成，次一交易日开盘才成交，严禁未来函数。
已落地复权漂移：前复权(qfq)在除权日会跳变，虚增收益。→ 统一用后复权(hfq)，baostock adjustflag=2 / akshare adjust=hfq。
已落地停牌幽灵订单：停牌日下单无法成交却计入市值。→ _is_suspended 跳过，并计数 suspended_skipped。
已落地退市中途：篮子内某票在回测区间中途退市，K线断档。→ 引擎检测"窗口内最后交易日后仍持仓"即按最后可得价强制平仓并计入 delisted_exits，不再冻结虚增净值（此前仅文案标注幸存者偏差）。

B 类 · 统计陷阱

已落地过拟合：参数在样本上"调太美"。→ 样本外 walk-forward 70/30，分开报。
已落地样本量不足：单一年份可能只覆盖牛或熊。→ 单年跑批会标注，建议多周期交叉验证。
已落地幸存者/选择性呈现：只晒最好的一段。→ 报告要求完整时段，不挑区间。

C 类 · 执行陷阱

已落地零成本虚高：不扣费回测天然高估。→ 真实成本模型：佣金万2.5（单笔最低5元）+ 印花税0.05%（仅卖）+ 滑点0.1%（双边）+ 过户费0.001%。
已落地涨跌停：涨停买不进、跌停卖不出。→ 主板10%/双创20%板近似（baostock 无字段用涨跌幅），涨停跳过买入、跌停跳过卖出。
已落地T+1：当日买入不能当日卖。→ 调仓在次交易日开盘执行，自然满足。
已落地流动性：小票可能根本买不到量。→ 默认篮子为流动性较好的标的，另做成本 2× 敏感性。

D 类 · 报告陷阱

已落地不只看收益/胜率：报 夏普 / 索提诺 / 卡玛 / 盈亏比 / 月度收益，单一指标会骗人。
已落地实盘折扣：回测通常比实盘高 30–50%。→ 报告明示"现实折扣"护栏。
已落地完整时段：避免挑最好区间展示，统一输出全周期。

二、一把尺子口径（各模块统一度量）

  • B7 回测：所有绩效指标（总收益/年化/最大回撤/夏普/索提诺/卡玛/胜率/盈亏比）均由同一条组合净值曲线 _metrics_from_nav 单一派生；顶层便捷指标与 metrics（基准成本）同源，metrics_2x 为 2× 成本情景（数字本应不同，二者均经同一派生函数断言一致）。

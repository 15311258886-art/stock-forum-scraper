  server.py:628-642  _send_json：删掉无条件 `Access-Control-Allow-Origin: *`；

  server.py:665-678  _guard_write()：① Host 非回环 → 403（防 DNS rebinding）；
                     ② Origin 存在但非回环 → 403；③ Content-Type 非 application/json（允许带 charset）→ 415。
  server.py:812-832  _do_POST：5 个写接口（login_check / fetch / demo / overseas / sync_names）在**路由前**
                     统一过 _guard_write；请求体 json.loads 失败 → 400（原为静默降级成 {} 后照常执行，
                     最危险的一处）；body 不是 JSON 对象 → 400。

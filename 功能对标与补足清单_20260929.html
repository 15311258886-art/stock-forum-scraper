三、补足清单（A 下钻补全 ｜ B 信息深度补全）

A1 · 板块详情页下钻 P0

现状：板块名死胡同（板块动向、板块资金流）。竞品：东财「最强板块」。
建议做法：点板块名 → 板块详情页：①成分股全列表（可排序/筛选）；②板块 K线 + 分时资金曲线；③板块内个股资金净流入对比榜；④板块 PE 中位数 / 估值分位；⑤板块内龙虎榜；⑥板块内「诊股」入口（批量）。
实施量：中（需后端板块成分股+板块行情接口；前端新增 p-board 面板 + renderBoard）。

A2 · 个股诊断第4层 P0

现状：估值/财务/公告/研报展示即止。竞品：东财 F10。
建议做法：
  • 估值：点因子 → 因子明细 + 历史分位 + 同业对比
  • 财务：点指标 → 历年趋势图（营收/净利/ROE/毛利率按年季）+ 杜邦分析树
  • 公告：点标题 → 原文链接 / 摘要
  • 研报：点 → 研报池（多份原文 + 摘要 + 目标价分布）
  • 新增段：股东研究（人数变化/十大流通股东）、融资融券、北向资金、机构调研、题材概念、个股龙虎榜
实施量：大（多接口 + 多图 + 交互下钻）。

A3 · 个股页社区情绪聚合 P1

现状：股吧/雪球情绪在独立面板，未聚合到个股。竞品：东财个股页聚合股吧、新浪个股页聚合讨论。
建议做法：个股诊断页新增「市场声音」段，聚合该股票股吧热度 / 多空比 / 雪球讨论摘要。
实施量：中。

B1 · 财务可视化 P1

现状：12 行数字表。竞品：同花顺/雪球/财报说 趋势图 + 杜邦。
建议做法：趋势折线 / 柱图 + 杜邦树（可并入 A2 财务段）。
实施量：中。

B2 · F10 公司深度 P1

现状：概况仅主营业务 + 经营范围。竞品：东财 F10。
建议做法：主营拆解 / 产业链位置 / 竞争优势 / 风险提示高亮。
实施量：小—中。

B3 · 跨资产 / 宏观联动 P2

现状：无。竞品：新浪三层级立体分析。
建议做法：大盘 → 板块 → 个股联动解读（需在个股/板块页加「关联大盘/行业」入口）。
实施量：大。

B4 · AI 财报 / 事件摘要 P2

现状：规则引擎专家卡（浅）。竞品：妙想 / 芝麻AI / 千问深度研究。
建议做法：自然语言问财报、研报一键提炼（需 LLM 或本地模板生成）。
实施量：大。

B5 · 产业链上下游联动 P2

现状：无。竞品：东财知识图谱 / 新浪产业链受益股。
建议做法：点个股 → 所在产业链 → 上下游受益股列表。
实施量：大（需产业链数据）。
